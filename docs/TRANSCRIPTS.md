# Transcript format version 1

This repository defines a local SHAKE256 encoding because Hermine does not
publish a canonical byte-level instantiation of its random oracles. It is not an
official interoperability format.

The preimage starts with ASCII `hermine-rs/transcript/v1`, a zero byte, and one
domain byte. Domain values are 1 for H_c, 2 for H_beta, 3 for matrix expansion,
4 for key identity, 5 for session identity, 6 for refresh identity, and 7 for
experimental DKG. DKG subprotocols additionally bind a `kind` field.

Each field appends the following bytes in order:

```text
u64_le(label_length) || label || u64_le(value_length) || value
```

Integer fields encode their value as eight little-endian bytes. Order, labels,
empty values, and field boundaries are significant. Raw digest extraction reads
the requested number of SHAKE256 output bytes.

Challenge extraction appends `ring-degree`, `ring-modulus`, and
`challenge-weight` integer fields. It samples distinct support positions using
partial Fisher–Yates selection and independent signs. Binding extraction appends
`ring-degree`, `ring-modulus`, and `binding-repetitions`, fixes beta_1 to +1, and
samples the remaining signed monomials uniformly.

Matrix extraction requires domain 3 and appends `ring-degree`, `ring-modulus`,
`matrix-rows`, and `matrix-columns`. It samples coefficients uniformly in
row/component/coefficient order using the same rejection extraction below.

Uniform extraction reads 16-byte little-endian words, retains the low
`ceil(log2(bound))` bits, and rejects values at least `bound`. A singleton range
uses no entropy. The complete signing/key field schemas are in `PROTOCOL.md`;
experimental DKG schemas are in `DKG-SUBMERSION.md`, `DKG-SHARING.md`, and
`DKG-ROUNDS.md`. The uniform-mask context and direct challenge-XOF encoding
are specified separately in `DKG-UNIFORM-MASK.md`.

The transcript builder is a primitive, not a complete protocol. Signing must bind
all H_beta inputs from Figure 7, including the key, signer set, message, and every
selected preprocessing commitment. H_c must bind the key, message, and aggregate
rounded commitment. The high-level signing builders enforce those schemas.

Independent Python/OpenSSL vectors are generated by
`python3 scripts/transcript_reference.py` and stored in `tests/data/transcript.txt`
and `tests/data/matrix.txt`.
